# MakeMIT 与全球顶级硬件黑客松拆解（灵感与工程铁律）

相对于单纯比拼模型 benchmark 分数（例如在统一真机平台和固定基座模型上微调 VLA、比拼任务成功率的竞赛），以 **MakeMIT**、**CMU Build18**、**MIT Reality Hack** 为代表的硬件黑客松，评审的其实是**“把数字智能变成物理体验”的产品力**。

---

## 一、MakeMIT x Harvard 2026 代表开源项目拆解

以下均来自 GitHub 上可查证的 MakeMIT 2026 真实参赛项目：

1. **[Locky](https://github.com/Vishvenugopal/Locky-MakeMIT)** — 戒手机躲猫猫小车
   - **痛点洞察**：所有手机自律 App 都能被用户顺手删掉或关掉。
   - **解法**：把手机物理锁进搭载激光雷达（iPhone LiDAR）和 Raspberry Pi 的 Viam 小车，扫描房间后**自动躲进用户视线死角**。
   - **为什么高级**：用**物理世界的不便利性与空间感**，解决软件永远解决不了的自律问题。

2. **[Scribblr](https://github.com/Yd025/Scribblr)** — 物理黑板粉笔抄写手
   - **解法**：采集讲课音频 → Gemini 提炼结构化笔记 → 转成单笔画 G-code → 驱动机械机构拿真粉笔在黑板上写重点。
   - **为什么高级**：把“AI 总结笔记”这个烂大街软件功能，拉回教室黑板的物理媒介，视觉冲击极强，而执行层本质上是确定性的 G-code 绘图机。

3. **[Auto-Focus Glasses](https://github.com/laoeked1111/plase-read-instructions)** — 免手触声控物理变焦眼镜
   - **痛点洞察**：外科医生、电工双手占满工具时，想看清微小细节只能凑近或眯眼。
   - **解法**：Pi Zero 2 + Pi Pico + 步进丝杆物理移动镜片 + 语音指定目标（Gemini 辅助锁定位置）+ 镜腿 OLED 动画与语音反馈。
   - **为什么高级**：需求极度具体，执行机构（丝杆调焦）简单可靠。

4. **[Bless You Polar Bear](https://github.com/NaemBi-Bap-MAKE-MIT-2026-Team)** — *Sustainability 三等奖*
   - **痛点洞察**：独居异乡打喷嚏时没人说一句 "Bless you"。
   - **解法**：Raspberry Pi + 方形 LCD + 扬声器藏进北极熊玩偶，**本地抗噪小模型实时检测喷嚏声**，触发温暖动画与语音关怀，并结合天气/花粉信息给出贴心建议。
   - **为什么高级**：极小的情感切口 + 极强的端侧实时触发体验，不需要复杂机械臂也能打动评委。

5. **[Whackathon](https://github.com/antaramazumdar/makemit)** — 反“虾系驼背”惩罚椅
   - **痛点洞察**：工程师写代码弓背成虾，软件弹窗提醒毫无威慑力。
   - **解法**：椅背部署多路测距传感器检测脊柱塌陷，一旦检测到驼背立刻触发物理负反馈。

6. **[A.L.I.C.E. MedDispenser](https://github.com/preespp/MakeMIT_2026_Team7)** — 智能分药终端
   - **工程架构典范**：Jetson 本地运行 RealSense + InsightFace 人脸识别（不依赖云端鉴权），通过 USB 串口向 ESP32 发送严谨的校验帧控制电机出药；前端由明确的 **10 态有限状态机（FSM）** 驱动触摸屏 UI；Gemini 只负责出药后的可选健康建议，**且自带严格 JSON 解析与本地规则引擎降级**。

## 二、同类高含金量参考赛事

- **CMU Build18** (<https://www.build18.org/garage>)：每年春季 100 支队伍、$250–$300 预算自由造物。代表了一种宝贵的黑客松美学——**认真地用工程能力做荒诞但精准直击情绪的装置**（如“只弹 Wonderwall 的吉他”）。
- **MIT Reality Hack** (<https://www.realityhackatmit.com/>)：聚焦空间计算、穿戴硬件与 AI，极擅长做**无障碍辅助、人类感官增强与情感记忆叙事**（例如为认知障碍老人设计的日常记忆辅助系统）。
- **Hackaday Prize** (<https://prize.supplyframe.com/>)：全球开源硬件奥斯卡，虽然是长周期赛事，但其历届入围项目在**“开源可复现性 + 解决真实世界问题”**上是最好的产品校准基准。

## 三、提炼给 48 小时硬件黑客松的 4 条工程铁律

1. **端侧只做小而准的实时感知**：人脸/手势/关键点/距离/音频事件，延迟压在几十毫秒内。
2. **用确定性有限状态机（FSM）兜底交互**：绝不把机械动作的安全与节奏交给不可控的端到端大模型输出。
3. **机械结构越简单越容易出彩**：云台（2–3 自由度飞特舵机）、2D 滑台（G-code）、磁吸递送位、轮式/现成机器狗底盘——把精力省下来打磨**外壳质感、灯光声音表情、交互曲线**。
4. **“物理强制力”或“情绪共鸣”二选一做到极致**：要么像 *Locky / Whackathon* 一样用物理世界打破软件的无力感，要么像 *Bless You Polar Bear* 一样让硬件长出情绪温度。
